# Терминология

**Предок Петрова** - участник, пригласивший Петрова, пригласивший пригласившего Петрова и т.д. Участник c ID 1 является общим предком для всех участников

**Наставник Петрова** - Участник, непосредственно пригласивший Петрова. Наставник есть у всех, кроме ID 1

**n-ная линия Петрова** - Группа участников, находящихся в структуре Петрова, где n - количество участников между ними + 1. Например, любой участник находится в первой линии своего наставника, а его первая линия является частью (т.к. первые линии других участников из первой линии наставника также формируют вторую линию наставника) второй линии своего наставника.

**Приглашённый Петрова** - любой участник из первой линии Петрова

**Структура Петрова** - участники из всех линий Петрова

# Депозиты

C каждого депозита участник получает 10% каждые 30 календарных дней, которые может выводить каждый 30 день, начиная с даты создания депозита.

# Статусы 

Каждый участник обладает статусом инвестора и структурным статусом.

## Статус инвестора

* Если участник внес 15000 USDC и больше: гуру (Guru)
* Если участник внес от 1500 до 15000 USDC: фанат (Fan)
* Если участник внес меньше 1500 USDC: любитель (Amateur)

## Структурный статус

На структурный статус, участника влияет количество участников со статусом "фанат" в его первой линии.

### Репрезентация структурного статуса

**5 звезд** получает участник, в первой линии которого есть 10 участников со статусом инвестора "фанат"

**4 звезды** получает участник, в первой линии которого есть 8 участников со статусом инвестора "фанат"

**3 звезды** получает участник, в первой линии которого есть 7 участников со статусом инвестора "фанат"

**2 звезды** получает участник, в первой линии которого есть 6 участников со статусом инвестора "фанат"

**1 звезда** получает участник, в первой линии которого есть 5 участников со статусом инвестора "фанат"


### Реферальные бонусы и влияние на них структурного статуса

Реферальные бонусы – это выплаты отчислений с внесенной суммы своей структуры.

### Линии и получаемые с них реферальные бонусы

C первой линии участник всегда получает 5%

### Расчет суммы, которая будет умножаться на реферальный %

Петров пригласил Иванова.

Иванов внёс 1000. С них Петров получил 5%, то есть, 50.

Петров вывел 500.

Петров внёс 700. Петров получил 5% от 200, так как максимальный депозит изменился на 200, а за 500 Петров получил бонусы при первом взносе.
